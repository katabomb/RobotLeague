# ロボットリーグ（Robot League）

**ロボットを設計し，戦いを観戦し，世代を重ねてリーグを進化させるブラウザゲームです．**

赤・青・黄の3機の自律型ロボットが対戦します．プレイヤーは最下位の機体を改良し，装備と行動パターンを工夫して上位を目指します．最下位から脱出できれば，新しい世代のリーグへ進むことができます．

現行版：試作版 Step3（ルールv4）

## 遊び方

[`robot_league.html`](robot_league.html) をブラウザで開いてください．インストールやサーバーは不要です．

1. 現在の正式評価と各機体の戦績を確認する．
2. 最下位の機体の装備や行動パターンを変更する．
3. 改良機による全試合を連続観戦する，または試験評価ボタンで結果を確認する．
4. 改良機が最下位から脱出したら，次世代URLを発行する．
5. 発行されたURLを開き，新しい世代のリーグで再び改良に挑戦する．

## 戦闘環境

円形の闘技場に3機のロボットが集結します．敵の位置は常に把握できますが，弾丸を命中させるには正確な照準と移動予測が必要です．障害物は地面の溝のようなもので，移動を妨げますが，視界や射撃は遮りません．戦場の外周や障害物に達したロボットは，衝突を避けるように進行方向を反転させます．

弾丸には有限の飛翔速度があり，発射された後でも回避できます．停止して狙えば精度は向上しますが，敵の攻撃を回避しにくくなります．移動・照準・射撃には共通のエネルギーを使用します．

## 機体の設計

装備の数値は機体の性能そのものではなく，**複数の性能を決定する設計パラメーター**です．装備の増強は重量や機体サイズにも影響するため，組み合わせを考える必要があります．

| 装備 | 役割 |
| --- | --- |
| 動力 | モーターの出力．移動速度と旋回能力は重量との比によって決まる． |
| 装甲 | 被弾時のダメージを軽減する．重量も増加する． |
| 火力 | 弾丸一発の威力．高火力ほど射撃時の消費エネルギーが増える． |
| 射程 | 弾丸の最大到達距離．上限がある． |
| センサー | 照準と敵の移動予測の精度．敵の発見距離には関係しない． |
| 電源 | エネルギーの蓄積容量と回復速度を決める． |

装備設定に応じて，重量，機体半径，最高速度，旋回速度，射程，弾丸の威力，射撃消費エネルギーなどが計算されます．装備値は非負の整数で，機体半径には出場上限があります．

## 行動パターン

ロボットは次の3つの状況に応じて行動を切り替えます．

- **敵が射程外**：最も近い敵が自機の射程外にいる．
- **敵が射程内**：最も近い敵が自機の射程内にいる．
- **敵の弾が接近中**：自機への弾丸の接近が予測される．最優先で判定される．

各状況に最大8手順を設定でき，上から順番に実行して繰り返します．状況が変わると，切り替わった行動パターンの最初から実行します．

| 設定 | 内容 |
| --- | --- |
| 移動 | 停止・前進・後退・敵へ・敵から・周回 |
| 角度 | 基準となる移動方向からの角度．詳細設定で編集可能（停止・後退には適用されない）． |
| 速度 | 最大移動速度に対する割合（0～100%）．実際の速度は旋回やエネルギーにも左右される． |
| 照準 | ONにすると照準時間に応じて射撃精度が向上する．OFFでも射撃可能． |
| 射撃 | ONの間，射程・エネルギーなどの条件を満たせば射撃する． |
| 秒 | 手順の継続時間（0.1～5秒）． |

移動方向と射撃方向は独立しています．通常設定では角度欄の編集が無効になり，詳細設定で編集できます．既存の角度設定は詳細設定を閉じても保持されます．

## 大会と観戦

1大会は5競技，各3試合の計15試合で構成されます．観戦時は改良前の正式評価を基準として，次の順序で進行します．

1. 上位2機の対戦
2. 上位機のうち下位の機体と改良対象機の対戦
3. 上位機のうち上位の機体と改良対象機の対戦
4. バトルロワイヤル（平地）
5. バトルロワイヤル（障害物あり）

各試合は最大45秒です．1対1では2点・0点，三つ巴では2点・1点・0点を配分し，同順位の場合は該当順位の得点を均等配分します．各競技の3試合の平均得点を合計し，総合順位を決定します（満点8点）．時間切れの場合，生存機は与えたダメージと残存HPの半分の合計を基準に順位を決めます．撃破された機体は生存時間で順位を決めます．

- 全15試合の連続観戦と個別試合の再生
- 正式機・改良機の切り替え
- 一時停止・再試合・1／2／4／8倍速再生
- HP・エネルギー残量・射撃に必要なエネルギー量の表示
- 観戦済み試合に基づく暫定順位と最終順位の表示

乱数シードと初期配置を固定しているため，同じルール・機体・試合条件で戦闘を再現できます．

## 世代交代と記録

現在の正式評価はその世代の確定済み機体に対する評価です．試験評価では改良前後の得点と順位を比較できます．改良機が最下位から脱出した場合（同率最下位を除く），次世代URLを発行できます．

各機体には登場世代，在籍世代数，累積優勝回数，現在の連続優勝回数，最多連続優勝回数が記録されます．単独首位を優勝として数え，改良されずに残った機体の記録は次世代へ引き継がれます．改良機は新機体として記録を開始します．試験評価や再観戦だけでは正式な記録は更新されません．

リーグの情報はURLのフラグメントに格納されます．URLを保存・共有することで，その世代のリーグを再開できます．機体単体のJSON書き出し・読み込みにも対応しています．旧ルールバージョンのURL・JSONとは互換性がありません．

## 設計思想

- 単純で理解可能なルールから，多様な戦術や予測しにくい戦闘結果を生み出す．
- 装備間のトレードオフと行動パターンの組み合わせを重視する．
- 機体を設計する楽しさと，大会を観戦する楽しさを両立する．
- 世代交代を通じて，新たな挑戦者や長く君臨する王者が自然に生まれることを目指す．

## 技術構成

- HTML / CSS / JavaScript による単一HTMLファイル
- Canvasによる2次元戦闘の描画
- 外部ライブラリ・サーバー・データベース不要
- DOMに依存しない戦闘エンジン（Node.jsでの自動対戦にも利用可能）
- 1/30秒刻みの戦闘計算，有限速度の弾丸，予測射撃，移動機体との衝突判定

## 開発状況と今後の課題

現在は試作段階です．Step3では観戦機能，操作性，境界での反射処理，世代交代条件，機体の戦績記録を改良しました．

今後は，装備を一律に増強した大型機体が強くなりすぎないか，特定の機体や戦術が支配的にならないか，適切な戦闘時間が確保されるかなどを，自動対戦と実際のプレイを通じて検証していく予定です．ブラウザ上での連続観戦や世代交代の一連の操作についても検証を進めます．
